# skills

Reusable AI-agent skills for Yap's projects.

| Skill | Use |
|---|---|
| [`self-explaining-tour`](self-explaining-tour/SKILL.md) | Add a guided tour / self-explaining onboarding and demo mode to a web or webview app. |

Each skill has a `SKILL.md` with YAML frontmatter (`name`, `description`), a workflow, rules, and a checklist. Skills point at the reusable modules in this repo instead of copying code into the instructions.
