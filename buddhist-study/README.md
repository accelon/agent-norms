## 這一版的重點

- **來源**：阿含、律藏、論藏、大乘經、禪門語錄；不重寫原文，只建立版本、經號、卷、頁、欄、行的座標。
- **主張類型**：名相定義、教義命題、修行位次、戒律規範、人物傳承、版本異說。
- **例子**：菩提心 → 6 條主張（定義／發心／願行／位次／出處／異說）。這是示意，不是已完成條目。
- **人物政策**：佛學知識庫只收古德高僧等已蓋棺論定的人物；當代行者留給華嚴大詞典，以授權、揭露、可撤處理。
- **高風險**：教義判攝、修行指導、戒律判定須專家審核，高風險雙人簽核；不提供醫療建議。
- **金句**：「佛學是修行的地圖，不是所知障」是本項目宗旨，不是經文原句；第 4 頁已加註。
- **開源**：核心開源；共建者優先使用；服務與培訓支持長期維護。
- **成本結構**：02 有 pie chart：算力 5%、專家 68%、團隊運營 27%；並列「為什麼現在可行」兩條理由。

## 05 技術優勢

05 沿用中醫版 05 的版型與三項技術資產，只把領域詞換成佛學：

- 組字專利：佛學名相、梵巴譯名、異體字，遇到字型沒有的字時，用「拼形序」遞迴組字。
- 大規模紙書標記與處理：93 個古籍庫、47 億字、大正藏 690 萬行、6,357 組 T↔K 卷對照。
- 巢狀探索：菩提心 → 點「菩提」→ 展開一層 → 點「華嚴經」→ 經典原文。

三項技術資產、專利號、字庫數字、47 億／6,357 組、分離標記定義都不要改；那些是技術護城河，不是佛學主張。05 的 47 億字是佛典語料管線經驗，不是「佛學知識庫已完成 47 億字標記」。

## 重出 JPEG

```powershell
$base = "D:\2026\agent-norms\buddhist-study"
$edge = "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe"
$url  = "file:///" + ($base -replace '\\','/')
$pages = @(
  @('01','三層架構'), @('02','人機合作與成本'),
  @('03','算力與共建'), @('04','為什麼要做'),
  @('05','技術優勢')
)
foreach ($p in $pages) {
  $id = $p[0]; $name = $p[1]
  & $edge --headless=new --disable-gpu --hide-scrollbars --no-first-run `
    --user-data-dir="$base\edge-$id" --force-device-scale-factor=1 `
    --window-size=1080,7000 --screenshot="$base\raw-$id.png" `
    "$url/$id.html"
  python "$base\trim_one.py" "$base\raw-$id.png" "$base\佛學知識庫-$id-$name.jpg"
}
```

Edge 有時會在程序返回後才寫檔；上面的迴圈若出現 `FileNotFoundError`，把 `trim_one.py` 那行改成寫檔後再跑一次即可。

## 邊界

- 不是佛典全文資料庫，也不是修行指導手冊；它是入門與查證層。
- 不把「佛學是修行的地圖」說成經文；不以單一詮釋壓掉部派、版本與異說。
- 不宣稱已標記完整大藏經；現有 47 億字是管線經驗，不是本知識庫的完成量。
- 當代人物不進佛學知識庫；需要當代案例時，走華嚴大詞典的授權與揭露流程。
